## 二、作品是什么

**在线 playable 链接（打开即玩，无需登录/安装）：**
https://ai-please-vko0yoa0x8a.qoder.zone

《AI, PLEASE · 请调好你的模型》是一个像素风「搭配AI」换装小游戏：
你经营一家「模型裁缝铺」，给 AI 娃娃穿外套、调温度、塞上下文、选人设、拉对齐、开关联网……
同一道互联网热梗问题（city不city / 那咋了 / 疯狂星期四v我50 / 哈基米 / 班味 / 红温……），
不同参数搭配会产出完全不同的预设答案；答完交给像素应用商店，
由预设「用户」（momo、用户_已注销、键盘侠退休中……）打 1–5 星并留下梗评论。

- 5 天 × 5 单 ≈ 8 分钟一局；商店均分跌破 2.0 星提前「下架」失败。
- 8 个换装控件即时反映到娃娃外观与表情（高温脸红抖动、低记忆背小包、高对齐抱宪法、氪金戴金链）；6 底座（量子玄学 / 祖传包浆 / 海归夹英文）× 10 人设外套（牛马代言人 / 赛博月老压轴解锁）。
- 「顾客喜好纸条」揭示顾客六维偏好中的五维，被掩的一维写明「温度随缘 / 人设随缘 / 底座随缘」等——好评靠搭配直觉，不靠瞎猜。
- 25 张工单 × 4 答案变体 + 39 条全局修饰（结巴/失忆/官腔拒绝/百度百科体/小作文膨胀/量子叠加/包浆老梗/海归夹英文），729,000 种参数组合永不空白；跨天首题不重复前一天末题。
- 130+ 条星级梗评论（含分工单定向评论）、《对齐真理报》每日结算、双结局 + 下架结局、对齐币解锁隐藏外套与隐藏工单、自动存档续玩、导出搭配卡 PNG。
- 画面与音乐全程序生成：640×360 像素整帧、离线合成音效与店铺 BGM（24 小节三段循环 · 约 46 秒，PvZ 式俏皮电子风：弹跳贝斯/八分琶音/铃铛点缀，旋律原创）、中文像素字形图集；零构建、零外链、零真实 AI 调用。

## 三、为什么做

1. **问题真实**：「调参」是 AI 时代的新常识，但温度、上下文、对齐这些词对普通人是一堵墙。
   我们把每个参数翻译成一件看得见的衣服：温度是围巾脸色、上下文是背包、成本是补丁或金链、人设是外套——
   换装即调参，玩一局就建立直觉。
2. **LifeHack 精神**：不接真模型、不烧 token，用「查表 + 修饰注入」把大模型的行为刻板印象演成喜剧；
   全预设反而让每个梗都能精确踩点，评委打开 3 秒就能玩到核心循环。
3. **致敬与差异化**：演出语法致敬《Papers, Please》与像素戏仿《IP, PLEASE》（MIT 引擎合法搬运），
   但世界观全虚构（对齐部 / 模型裁缝铺 / 《对齐真理报》），文案全部原创重写 + 自补热梗，不撞题材。

## 四、怎么用（5 步）

1. 打开链接，点「开始营业」。
2. 用 8 个控件给 AI 换装调参，娃娃即时变装；◀▶ 挑一张热梗工单。
3. 点「提问」，看打字机答案演出（点纸面可跳过）。
4. 「交给顾客」看应用商店星级与梗评论；攒对齐币解锁隐藏外套/工单。
5. 每天 5 单后读报结算，五天后迎接结局；均分跌破 2.0 星会被下架——再来一局。

## 五、怎么用 Qoder 做出来的

全程在 Qoder Desktop 内完成，开发—测试—部署闭环：

1. **Plan 模式定稿**：先探索比赛页与风格标杆站，产出含复用策略、数据 schema、里程碑与验收清单的实施计划，经确认后执行。
2. **并行 subagent 逛 GitHub**：调研 ip-please（MIT 引擎）、fusion-pixel（OFL 中文像素字）、chime（MIT 梗库）等候选，
   确定「搬引擎 + 自建游戏层」的合法复用边界，保留 LICENSE / OFL 与致谢。
3. **引擎搬运与游戏层开发**：多 script 零构建架构、640×360 离屏整帧、场景机与定时器队列；
   新写娃娃分层换装、8 控件工作台、答案/商店/报纸/结局演出、评分与修饰规则、存档与解锁。
4. **字形管线与门禁**：Python + Pillow 扫描全部源码与文案字符生成像素字形图集；
   `tools/check_chars.js` 缺字门禁阻断部署（1135 字零缺字）。
5. **ego-browser 脚本化回归**：`tools/playtest.js` 一键跑完 729,000 组参数遍历断言非空、
   通关/下架双路径、中途刷新续玩、导出下载、375/768/1440 三档 resize、50 连点压测、声音/全屏同步；
   过程中发现并修复了 1 星评论不可达、全屏文案不同步、报纸解锁跨刷新丢失等真实缺陷。
6. **Qoder Sites 一键发布**：MCP 工具 prepare → publish → 公开访问策略 → 公网链接线上回归
   （13 个资源全同源、零 console 错误），评委打开即玩。
